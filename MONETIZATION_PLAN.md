# 💰 План монетизации IQ Test (iqtestnow.org)

**Главный принцип:**  
Базовый быстрый тест остаётся **100% бесплатным, быстрым и без навязчивой рекламы**.  
Монетизация строится на двух потоках:
1. **Благодарность / поддержка инфраструктуры** (донаты на сервер через 1-клик Apple Pay / Google Pay).
2. **Премиум-артефакты** (именные PDF-сертификаты и детальный разбор способностей).

---

## 🚀 Фаза 1. Донаты на сервер («Keep It Free»)

### 1. Позиционирование и психология
* **Не «Купи мне кофе»** (на обезличенном сервисе просьба угостить незнакомца кофе конвертит хуже).
* **«Помоги тесту оставаться бесплатным и поддержи серверы ☕»**:
  - Модель Википедии: пользователь бесплатно получил результат и ценность.
  - Человек чувствует, что делает полезный взнос в проект, которым только что воспользовался.

### 2. Сетка донатов и экономика
| Сумма | Назначение | Психология | Экономика (Stripe: 2.9% + $0.30) |
| :--- | :--- | :--- | :--- |
| **$1** | Микро-донат | Минимальный барьер, мгновенный импульс по Face ID | Чистыми: ~$0.67 (33% комиссия) |
| **$3** | ☕ Серверный кофе | Базовая рекомендуемая сумма (выбрана по умолчанию) | Чистыми: ~$2.61 (13% комиссия) |
| **$5** | 🌟 Супер-саппортер | Для тех, кому очень понравился результат | Чистыми: ~$4.55 (9% комиссия) |
| **Custom** | Своя сумма | Для энтузиастов | — |

> **Почему исключили $0.50:** у банков и Stripe есть фиксированная комиссия **$0.30** за транзакцию. При платеже в 50 центов банк заберёт 31 цент (>60%), а вам останется всего $0.19.

### 3. Почему Stripe, а не PayPal
1. **Нативный Apple Pay и Google Pay:** на смартфонах (~51% трафика) оплата проходит в 1 тап двойным кликом по Face ID, без ручного ввода карты.
2. **Полная приватность:** в чеке и банковской выписке пользователь видит только **Statement Descriptor: `IQTestNow`**, а не личные ФИО владельца.
3. **Нет принудительного логина:** в PayPal.me требуется аккаунт PayPal и светятся личные данные, что обрушивает мобильную конверсию.

### 4. Чек-лист запуска Stripe
- [ ] Зарегистрировать аккаунт на [stripe.com](https://stripe.com) (~10–15 минут).
  - Тип: **Individual / Sole Proprietorship** (физлицо/самозанятый).
  - Данные: европейский/западный IBAN, фото паспорта/ID с телефона.
  - Сайт: `https://iqtestnow.org`.
  - **Statement Descriptor:** `IQTestNow` (короткий: `IQTEST`).
- [ ] Создать в Stripe Dashboard **Payment Link** в режиме *«Customer chooses what to pay»* (или с пресетами $1, $3, $5).
- [ ] Вставить блок поддержки серверов на экран результатов (`en/index.html` и `ru/index.html`).

## 🎓 Фаза 2. Платный PDF-сертификат и подробный отчёт ($2.99 – $4.99)

После завершения теста (быстрого или расширенного) на экране результатов предлагается:

1. **Именной PDF-сертификат высокого разрешения:**
   - Красивое официальное оформление с уникальным номером верификации, датой и именем.
   - Форматы для печати (A4) и для соцсетей / LinkedIn.
2. **Детальный разбор профиля интеллекта (Breakdown Report):**
   - Разрез по 4 доменам (Логика, Пространственное мышление, Память/Скорость, Вербальный интеллект).
   - Персональные рекомендации: какие когнитивные зоны сильные, а какие стоит потренировать.
3. **Механика выдачи:**
   - Оплата через Stripe Checkout (Apple Pay).
   - После успешного webhook воркер генерирует PDF и моментально отправляет на email через Resend, сохраняя покупку в базу D1.

## 📬 Фаза 3. LTV и удержание (База подписчиков)

* **Email-рассылка «1 задача в неделю» (уже собирается в D1):**
  - Раз в неделю отправляется интересная логическая головоломка с разбором.
  - В письме — напоминание пройти повторный тест для замера динамики + ссылка на тренировки памяти/внимания.
* **Telegram-канал / Бот:**
  - Альтернативный канал для пользователей, предпочитающих Telegram почте.

## 🌍 Разделение по регионам (Платёжные шлюзы)

* **EN / Global (~70% трафика):**  
  **Stripe** (Карты всех стран, Apple Pay, Google Pay, iDEAL, Bancontact).
* **RU (~30% трафика):**  
  Карты РФ через зарубежный Stripe не пройдут. Для RU на экране результатов можно параллельно показывать:  
  **Tribute** (Telegram-донаты в 1 клик с карт РФ) / **ЮMoney** / **Boosty**.
