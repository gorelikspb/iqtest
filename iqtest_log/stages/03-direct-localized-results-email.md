# Этап 3: Прямая отправка результатов на email пользователя (EN/RU)

**Дата**: 2026-08-27

## Что было

Сайт шлёт формы на Cloudflare Worker `https://iqtestemails.gorelikgo.workers.dev` (Resend). Проверено по живому `script.js` и GET воркера:

- `handleSendResultsSubmit` собирал `type, name, email, iqResult, shareUrl, source, timestamp` и **не передавал** `lang` / `currentLang`, хотя язык на сайте берётся из URL (`/en/` vs `/ru/`, `getCurrentLanguage()`).
- Воркер в репозитории (`functions/api/worker.js`) рендерил только русский HTML и слал письмо **на `ADMIN_EMAIL`** с `from: onboarding@resend.dev` и темой `[TEST for user@…]`. Английская версия сайта всё равно получала бы русское письмо, если бы оно вообще доходило до пользователя.
- Оператор пересылал письмо дальше (в т.ч. через `iqtestnoworg@gmail.com`). Это совпадает с ограничением Resend: пока From — `resend.dev`, доставка только на ящик владельца аккаунта.

## Решение

1. **Фронт** — `getEmailLang()` (`en` | `ru` из URL) во все payload’ы: результаты, форма на странице результата, стартовая форма, `full-tests.js`.
2. **Воркер** — шаблоны EN и RU; `To` = email, который ввёл пользователь; BCC админу (если это не тот же адрес). Убраны тестовый префикс темы и текст «перешли вручную».
3. **From** — `FROM_EMAIL` / `CORPORATE_EMAIL`, иначе пока `IQ Test <onboarding@resend.dev>`.
4. Ошибка Resend 403 больше не маскируется успехом: форма получает `success: false` и `hint` про верификацию домена.
5. Офлайн-тесты: `npm run test:email`.

Шаблоны вынесены в `functions/_lib/email.js`. Деплой воркера: `npx wrangler deploy` (`wrangler.toml`).

## Почему такое решение

Язык нельзя угадать по домену письма — только по URL, с которого отправили форму. Прямой `To` убирает цепочку пересылок. Верификацию домена в Resend код сделать не может: это DNS в дашборде, без секретов в git.

## Плюсы

- EN-путь → английское письмо, RU-путь → русское
- Пользователь получает письмо на свой адрес
- Админ видит копию, без ручной пересылки
- Тесты проверяют язык, получателя и 403 без фейкового success

## Минусы

- Пока домен не верифицирован в Resend, живая отправка на чужой ящик не пройдёт (ожидаемый 403)
- Сайт (Pages) и воркер (workers.dev) деплоятся отдельно: после merge нужно ещё задеплоить Worker

## Подводные камни

- `from` должен совпадать с верифицированным доменом (не оставлять `onboarding@resend.dev`)
- DNS-записи Resend в Cloudflare — **DNS only**, не proxied
- Секреты только в Cloudflare Worker Variables, не в репозитории

## Оставшийся шаг в дашборде (не код)

1. [resend.com/domains](https://resend.com/domains) → Add Domain → `iqtestnow.org` (или `mail.iqtestnow.org`)
2. Прописать DNS, дождаться Verified
3. Секрет воркера: `FROM_EMAIL` = `IQ Test <noreply@iqtestnow.org>` (хост = верифицированный домен)
4. Задеплоить Worker и прогнать живой тест из плана в `EMAIL_SETUP_PLAN.md`

## Живой тест (после деплоя воркера и верификации домена)

1. `/en/` → отправить результаты на реальный ящик ≠ владелец Resend → письмо на английском, без форварда
2. `/ru/` → то же → письмо на русском
3. В Network POST есть `"lang":"en"` / `"lang":"ru"`
4. Админ получает BCC, не единственный получатель и не обёртку `[TEST for …]`
